Python `unittest` framework gebruikt om een recursieve JSON-zoekfunctie (`json_search`) te testen en te corrigeren.

- `recursive_json_search.py` – de functie die JSON-data doorzoekt op een key

- `test_json_search.py` – unittests voor `json_search()`
